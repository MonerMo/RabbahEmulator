# rn-app

The debug app of the CM30 MDB Bridge. See the root README for how to build, test and run.

* `src/device/codec` - Module 5, the codec
* `src/device/session` - Module 6, the cashless session
* `src/device/testing` - the TypeScript puppet for Jest
* `src/features/debug` - Module 7, the screen
* `__mocks__/@rabbah/mdb-device.ts` - what Jest sees instead of the Turbo Module
